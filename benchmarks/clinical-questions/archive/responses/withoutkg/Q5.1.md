## SQL Query Used:
```sql
SELECT TOP 20
    c.concept_name as diagnosis,
    c.concept_id,
    COUNT(DISTINCT co.person_id) as patients_with_diagnosis,
    COUNT(co.condition_occurrence_id) as total_occurrences,
    ROUND(COUNT(DISTINCT co.person_id) * 100.0 / 379814, 2) as percentage_of_women_50s
FROM omop.person p
INNER JOIN omop.condition_occurrence co ON p.person_id = co.person_id
INNER JOIN omop.concept c ON co.condition_concept_id = c.concept_id
WHERE p.gender_concept_id = 8532  -- Female
AND (YEAR(GETDATE()) - p.year_of_birth) BETWEEN 50 AND 59  -- Ages 50-59
AND c.standard_concept = 'S'  -- Standard concepts only
AND c.invalid_reason IS NULL  -- Valid concepts only
GROUP BY c.concept_name, c.concept_id
ORDER BY COUNT(DISTINCT co.person_id) DESC
```
