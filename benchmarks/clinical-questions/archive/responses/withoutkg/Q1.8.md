### Methodology:

2. Find pneumonia diagnoses by searching for conditions containing "pneumonia" and including descendants of the main pneumonia concept (concept_id 255848)
3. Filter for encounters in the past year using visit start dates

### SQL Query Used:
```sql
SELECT COUNT(DISTINCT vo.visit_occurrence_id) as inpatient_pneumonia_encounters
FROM omop.visit_occurrence vo
JOIN omop.condition_occurrence co ON vo.visit_occurrence_id = co.visit_occurrence_id
JOIN omop.concept c ON co.condition_concept_id = c.concept_id
WHERE vo.visit_concept_id IN (8717, 9201) 
AND (LOWER(c.concept_name) LIKE '%pneumonia%' OR c.concept_id IN (
    SELECT descendant_concept_id 
    FROM omop.concept_ancestor 
    WHERE ancestor_concept_id = 255848
))
AND vo.visit_start_date >= DATEADD(year, -1, GETDATE())
AND c.domain_id = 'Condition'
AND c.standard_concept = 'S'
```
