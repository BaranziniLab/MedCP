2. **Main analysis query:**
```sql
WITH ra_patients AS (
  SELECT DISTINCT person_id
  FROM omop.condition_occurrence co
  JOIN omop.concept_ancestor ca ON co.condition_concept_id = ca.descendant_concept_id
  WHERE ca.ancestor_concept_id = 80809  -- Rheumatoid arthritis
),
adalimumab_patients AS (
  SELECT DISTINCT person_id
  FROM omop.drug_exposure de
  JOIN omop.concept_ancestor ca ON de.drug_concept_id = ca.descendant_concept_id
  WHERE ca.ancestor_concept_id = 1119119  -- adalimumab
)
SELECT COUNT(DISTINCT rap.person_id) as ra_patients_on_adalimumab
FROM ra_patients rap
JOIN adalimumab_patients ap ON rap.person_id = ap.person_id
```
